怎么获取 Token

  1. 用手机 Safari 或电脑浏览器打开学校登录页：打开智汇福大登录页
  2. 用学号和密码登录；学校要求短信验证码时照做。
  3. 登录成功会跳到晚点名签到页。点一下地址栏，把整段网址复制下来（iPhone：点地址栏 → 拷贝）。
  4. 回到这里，把整段网址粘贴到上面的“学校 Token”框，点底部“保存配置并暂停”，再依次点“只读预检”“恢复定时”。

网址只保留 token 部分，不会保存学校账号密码。Token 过期时预检会显示“学校认证未通过”，重复以上步骤即可。
