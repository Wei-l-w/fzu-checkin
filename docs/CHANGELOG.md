# 更新记录

## 2026-09-30

### 注册与审批

- 登录页支持申请注册和凭申请密码查询审核结果；公开注册默认关闭。
- 管理员可开关注册、复制入口链接、通过或拒绝申请并填写原因，列表默认折叠且限高滚动。
- 待审批申请与正式账户分开存储。审批只创建普通成员的独立空白档案，默认暂停签到，不访问学校服务。
- 申请和查询独立限流，计数持久化；口令只保存 scrypt 散列，不向管理员或其他申请人返回。
- 审批支持幂等与中断恢复；账户写入加文件锁，防止并发覆盖，已有同名档案不能被覆盖。
- 使用及容量限制见 [注册与审批](REGISTRATION.md)。

### 定时恢复

- 修正控制服务的只读文件系统设置，使受限的 root 控制代理能够创建成员定时配置。Web 和学校客户端权限不变。
- 恢复分为学校只读预检与系统定时器启用两个阶段；仅当系统确认定时器 active/ enabled 后才记录恢复成功。
- 启用或写回失败则重新暂停，关闭对应成员的 timer/service；出现新的暂停时不能覆盖用户操作。
- 页面优先显示最终结果，明确区分服务器定时器故障和学校认证失败，不再把预检通过误报为已恢复。

### 发布验证

- 215 项 Python 离线测试，以及 34 项前端测试（26 项浏览器、8 项坐标/地图单元测试）。
- 新增用例覆盖成员隔离、审批权限、并发与中断恢复、凭据保护、限流、定时启用失败和状态一致性。
- 浏览器测试不再依赖特定服务器路径，可使用 Playwright 管理的 Chromium 或显式指定浏览器。
- 发布内容仅含源码、示例、文档和测试，不包含实际账户、Token、通知凭据、个人坐标、运行状态或服务器回滚包。
